# ファスティング信号 v0.6

「考えなくていいファスティング」— 今が食事OKか・ファスティング中かを信号でひと目で確認し、1タップで記録する習慣化アプリ（PWA）。

## v0.6 の追加（からだの中）
- ホームに「からだの中」カードを追加。最後の食事からの経過時間で、体の状態の目安（消化・吸収中 → 後かたづけ → 切り替え準備 → 脂肪燃焼スイッチON → ケトン燃焼モード → 目標ゾーン）を表示
- 段階バーと現在位置、次の段階までの残り時間、日替わりのひとことコメント
- 経過時間は「前回の食事時間の終わり」と「記録した食事の時刻」の遅いほうから計算（記録忘れで長く見えないよう控えめに）
- ケトン重視のときは切り替えが早めに進みやすい旨を添える

## v0.5 の追加（量の調整）
- 「次にやること」の「📋 材料・量を調整」で、肉・魚・卵・チーズ・豆腐・アボカド・油などの量を −／＋ で変更でき、糖質・タンパク質・脂質・kcal がその場で再計算される
- 「この量にする」→「これを食べた」で、調整した量と栄養が記録と「今日の栄養」に反映される
- 記録済みの食事も「今日の記録」の［量］ボタンからあとで調整できる（「標準に戻す」で元の量に）
- 調整できる材料は100gあたりの栄養（八訂をもとにした概算）で増減分を計算

## v0.4.2 の追加
- 「次にやること」のおすすめに「🔄 ほかから選ぶ」を追加。全時間帯の定番メニュー（栄養つき）から選ぶか、一覧にないものを自由入力して今日のメニューに設定できる
- 選んだメニューは今日の流れ・記録にも反映。「別の候補」を押すと選択を解除して日替わりに戻る
- 「違うものを食べた」ボタンは「ほかから選ぶ」に統合

## v0.4.1 の追加
- ケトン重視の昼食に「ささみとアボカドのチーズ焼き＋半熟卵」を追加（糖質2g・タンパク質39g・脂質34g・約475kcal）

## v0.4 の追加（材料と量・栄養）
- おすすめメニューに栄養の目安（糖質・タンパク質・脂質・kcal、1人分）を表示
- 「📋 材料と量を見る」／ガイドのメニューをタップ → 1人分の材料・分量・作り方（人数を変えると分量も変わる）
- 外食・コンビニメニューは「注文のめやす」を表示
- ホームに「今日の栄養」：記録した食事の合計。ケトン重視では糖質30g（多くても50g）の目安バー、タンパク質は体重×1.2〜1.6gの目安
- 間食はガイドから「間食として記録」で何回でも記録可能
- 栄養は日本食品標準成分表（八訂）をもとにした概算。自分で追加したメニューにはデータなし

## v0.3.1 の修正
- 1タップ記録の直後に「取り消す」ボタンを表示（5秒間）
- 「今日の記録」一覧に削除ボタンを追加（食事・体調・体重は ✕、水分は −1）

## v0.3 の追加（ケトン重視）
- **食事スタイル**（設定タブ）：🥑 ケトン重視（糖質 1日30〜50g以下・標準）／🍚 通常 を切り替え
- ケトン重視では、おすすめメニューから主食・果物を外し、肉・魚・卵・豆腐・野菜・油が中心に
- 食べるものガイドに「避ける食べ物」と糖質の目安（おにぎり1個 ≒ 40g）を表示
- ファスティング中のガイドに塩分補給（切り替え直後のだるさ・頭痛対策）を追加
- 定番メニューの編集はスタイルごとに保存（v0.2で編集したものは「通常」に引き継ぎ）

## v0.2 の追加（「何を食べる？」「次は何をする？」への対応）
- **次にやること**：今の時刻と記録から、やることを1つだけ大きく表示（例：「今は朝食の時間です」＋おすすめメニュー＋「これを食べた」ボタン）
- **今日の流れ**：起床後 → 最初の一食 → 昼食 → 夕食 → 食事終了 → ふりかえり をタイムライン表示し「いまここ」を表示。食事はタップで記録・取り消し
- **食べるものガイド**：ファスティング中（飲んでOK／避ける）・最初の一食・昼食・夕食・間食ごとの選び方と定番メニュー
- **定番メニュー**：日替わりでおすすめ。「別の候補」で切り替え。設定タブで自分の定番に書き換え可能
- **筋トレ日**：オンにするとタンパク質のおかず追加を案内

## v0.1 でできること
- **ホーム信号**：🟢 食事OK／🟡 まもなく終了（残り30分）／🔵 ファスティング中を、残り時間のリングで表示
- **食事時間テンプレ**：平日・休日それぞれ「夕食を終える時刻」を設定 → 段階に応じて開始時刻を自動計算
  - 初期値：平日 〜20:00、休日 〜18:00
  - 第1段階 12時間 → 第2段階 14時間 → 第3段階 16時間（上限）
- **休日扱い**：土日は自動で休日。平日の祝日などはワンタップで切り替え
- **調整日**：外食・家族行事の日だけ時間帯をずらす（連続記録は途切れない）
- **1タップ記録**：食べた時刻・水分・体調（◎○△）・体重
- **今日のふりかえり**：✅ 守れた／🔄 調整日／・ 今日はできず
- **記録タブ**：スタンプカレンダー、連続日数、直近7日の達成、体重・体調の一覧
- **段階の提案**：2週続けて週5日 ✅ なら次の段階を提案（自動では上げない）。体調△が3日続いたら下げる提案
- **通知**：食事開始30分前・終了30分前・水分補給（アプリが動いている間）
- **安全**：初回の開始時チェック、16時間上限、カロリーや目標体重は設定しない
- **データ**：端末内（localStorage）に保存、JSONで書き出し・読み込み

## 使い方
1. このフォルダを GitHub リポジトリに置いて GitHub Pages で公開
2. スマホのブラウザで開き「ホーム画面に追加」
3. 設定タブで平日・休日の終了時刻を確認し、通知をオン

※ `index.html` をPCで直接開いても動きます（オフライン化と通知はhttps公開時のみ）。
